05 — ACERCA DE TAXOID

Ciencia + veterinaria + tecnología

🐾

TaxoID es una herramienta educativa orientada a apoyar la identificación de insectos y artrópodos relevantes para la medicina veterinaria, entomología y salud animal.

La plataforma puede ampliarse progresivamente con nuevas especies, fotografías, claves taxonómicas, caracteres diagnósticos y datos relacionados con hospedadores y enfermedades.

⚠️ Importante

La coincidencia mostrada por el sistema representa una comparación con la base de datos disponible. No constituye por sí sola una identificación científica definitiva. Los resultados deben verificarse mediante claves taxonómicas, literatura especializada y profesionales competentes.
